# 夜班训练

独立 React + TypeScript + Vite PWA。所有记录仅存于当前浏览器的 localStorage，无账户、无服务端上传。

## 运行

```sh
npm install
npm run dev -- --host 0.0.0.0 --port 5188
npm test
npm run build
npm run preview -- --host 0.0.0.0 --port 5189
```

本机预览 `http://localhost:5188`。同一 Wi-Fi 下的 iPhone 可尝试 `http://192.168.31.94:5188`，IP 可能变化，且 Windows 防火墙需允许访问。开发服务仅供本地预览。

## iPhone 安装与离线

Safari「分享 → 添加到主屏幕」。可靠 PWA 离线需要 **HTTPS** 或本机 localhost 的安全上下文；iPhone 访问电脑的局域网 HTTP 地址不满足该条件。正式使用时将 `dist` 静态文件托管于可信 HTTPS 地址，或自行配置受设备信任的本地 HTTPS。项目不会自动发布。

`npm run build` 生成带内容版本号的 Service Worker，预缓存完整应用壳、JS、CSS、PNG 图标和 manifest。开发模式不注册 Service Worker；生产首次联网成功后，关闭再打开即可验证离线。新版本在旧页面关闭后接管。更换域名、端口、浏览器或主屏幕容器可能得到独立存储，需要手动导出、导入 JSON。

## 班次与作息

「我的」中可设置本次固定夜班开始/结束日期（例如本月14–19日），不是每月自动重复。夜班提示为14:00起床、15:30训练、17:30补觉；其他日期按白班08:00–20:00工作，建议下班后20:30训练、22:30睡觉。提示不会自动切换训练日。

## 数据与日期

22 天为推、拉、腿、休、上、下、有氧三轮加恢复日。目标组数 1–8，可调整有氧时长。默认 185 cm、185 斤为个人基线，不伪造每日体重。7 日均值只统计截至所选日期的实际体重；趋势显示近 14 日实际记录。重量单位 kg，身体体重单位斤。

日期使用本地日历和 UTC 日期序号进行天数运算，避免夏令时误差。打开应用时选今天，跨午夜不会自动切换训练记录。超出周期的日期保留其日志，训练模板显示首日或末日，并有提示。修改开始日期不移动历史数据。减少目标组数不会删除原有组记录。

休息计时保存结束时间，刷新或后台恢复后按真实时间计算；不承诺后台通知或声音。备份执行版本、日期和数值校验，导入覆盖前二次确认。读取损坏数据时停止自动覆盖，并允许导出原始数据。浏览器配额耗尽时显示保存错误；请及时导出备份。计划只作训练参考，非健康结果承诺或医疗建议。
